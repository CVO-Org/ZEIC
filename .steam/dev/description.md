# ZEIC - DEV Version
**This is the development version of [ZEIC - Zeus and Eden Interiors Community Version](https://steamcommunity.com/sharedfiles/filedetails/?id=3567067667).**

It gets every pre-release before it reaches the stable version, so things may break, change or disappear. Use it to test new features and report what you find; for your missions and ops, use the stable version. What the mod does is explained on the stable page.

- **Don't load both versions at the same time.** They contain the same addons.
- **Multiplayer: the server needs ZEIC too** (Interior Fill, Advanced Fill and the Move AI trigger run there). Other players don't.

# What's different from the stable version
- The **Change Notes** tab of this page lists what each pre-release changed.
- Every version in detail: [Releases on GitHub](https://github.com/CVO-Org/ZEIC/releases)
- Right after a stable release, DEV and stable are the same, until the next pre-release.

[h1]ZEIC - DEV Version[/h1]
[b]This is the development version of [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3567067667]ZEIC - Zeus and Eden Interiors Community Version[/url].[/b]

It gets every pre-release before it reaches the stable version, so things may break, change or disappear. Use it to test new features and report what you find; for your missions and ops, use the stable version. What the mod does is explained on the stable page.

[list]
[*] [b]Don't load both versions at the same time.[/b] They contain the same addons.
[*] [b]Multiplayer: the server needs ZEIC too[/b] (Interior Fill, Advanced Fill and the Move AI trigger run there). Other players don't.
[*] Report bugs and feedback on [url=https://github.com/CVO-Org/ZEIC/issues]GitHub[/url], or in the discussions of the stable version.
[*] Every version in detail: [url=https://github.com/CVO-Org/ZEIC/releases]Releases on GitHub[/url]
[/list]

[h1]Differences to the stable version (1.0.1)[/h1]
The current pre-release is [b]2.0.0[/b], a rework of the whole mod.

[h3]New[/h3]
[list]
[*] [b]Advanced Fill[/b]: furnishes and garrisons buildings in one go (interior first, then the units), with a collision check so units don't end up inside furniture, and fill modifiers: Military defences only, No modern electronics, Cold War era.
[*] [b]Area fills[/b]: Interior Fill and Garrison Building work on a share of the buildings within a radius, with a radius preview.
[*] [b]Processing queue[/b]: large fills run over several frames instead of freezing the game, with progress shown on the buildings.
[*] [b]Electronics (old)[/b] type for Fill Table / Shelf.
[/list]

[h3]Changed[/h3]
[list]
[*] All dialogs redesigned in the ZEN style; descriptions and shortcuts as tooltips.
[*] Templates live in config, split per mod (vanilla, CUP, GM, SOG, ...); missions and mods can add their own categories.
[*] Interior Fill: simple objects, normal objects or editable in Zeus; shortcuts (Alt repeats the last fill, Ctrl/Shift fill a category directly).
[*] Garrison Building: units as a percentage of each building's positions with a live estimate; one faction + subcategory list with side filter, search and recently used; asks before creating over 400 units.
[*] Move AI trigger: only on the server, only for enemy players, releases all units after 30-120 s.
[*] Object Fill is now called [b]Fill Table / Shelf[/b].
[*] Eden: everything ZEIC places is sorted into layers.
[/list]
